## 三个下单后才会撞上的限制

**80 和 443 的封锁是硬限制。** 官网在住宅 IP 机型的参数下面用加粗写明不开放这两个端口，理由是 IP 风控。这不是配置问题，提工单也改不了。

**IRVINE-PRO 会拒绝外部扫描。** 官网原文写它拒绝一切外部探测与扫描，未配置前访问受限，只有白名单或端口转发过去的设备能连。稳定性确实更好，代价是你从新网络连不上时，先别怀疑机器挂了。

**小带宽链路的拥塞控制要自己调。** 有测评记录过一台 10Mbps 三网精品机，默认 cubic + fq_codel 下联通单线程只有 0.4–0.6Mbps，重传 2.6%–5.1%，换成 BBR + fq 之后才恢复到可用水平。SixtyNet 的端口档位大得多，但高延迟链路上单线程吞吐受拥塞控制算法影响这件事一样成立，拿到机器先看一眼当前的算法。
